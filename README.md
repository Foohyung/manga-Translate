# MangaTranslate

เว็บแอปแปลมังงะ มันฮวา มันฮัว — ดึงข้อความจากภาพ (OCR) แปลภาษา ลบข้อความต้นฉบับ แล้วจัดตัวอักษรได้อิสระ
(ลากย้ายตำแหน่ง ปรับขนาดกรอบ ขนาดตัวอักษร สี ฟอนต์ เส้นขอบ พื้นหลัง และการหมุน) ก่อนดาวน์โหลดเป็น PNG หรือ ZIP

สร้างด้วย Next.js (App Router), React, TypeScript, Tailwind CSS และ Zustand

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

แล้วเปิด <http://localhost:3000>

### ตั้งค่า OCR (แนะนำ)

คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `OCR_SPACE_API_KEY`
(ขอคีย์ฟรีได้ที่ <https://ocr.space/ocrapi/freekey>) — ถ้าไม่ใส่ จะใช้คีย์ทดลอง `helloworld`
ที่ทุกคนใช้ร่วมกัน จึงมักถูกจำกัดจำนวนครั้ง (ระบบจะแจ้งให้รอสักครู่)

## โครงสร้างโปรเจกต์

```
src/
  app/                หน้าเว็บและ API routes
    page.tsx          หน้าแรก
    worktable/        โต๊ะทำงานแปล (editor)
    api/ocr/          อ่านข้อความผ่าน OCR.space (เก็บคีย์ไว้ฝั่งเซิร์ฟเวอร์)
    api/translate/    แปลภาษา (Google Translate → MyMemory)
  components/
    editor/           ส่วนประกอบของ editor (เวที, กรอบข้อความ, แผงปรับแต่ง ฯลฯ)
    ui/               ปุ่มและช่องกรอกที่ใช้ร่วมกัน
  hooks/              React hooks (คำสั่งของ editor, คีย์ลัด, การโหลดฟอนต์)
  lib/                ตรรกะหลัก: OCR, การตัดบรรทัด/วาดข้อความ, ลบข้อความเดิม, export, การบันทึก
  server/             โค้ดที่รันเฉพาะฝั่งเซิร์ฟเวอร์ (เรียกบริการภายนอก)
  store/              สถานะของโปรเจกต์ (Zustand) และขั้นตอน ดึงข้อความ → ลบ → แปล
```

## หลักการทำงาน

- **ดึงข้อความ** — ส่งภาพเป็น PNG ไปที่ OCR.space (Engine 2 อ่านภาษาญี่ปุ่นแนวตั้งได้) ภาพเล็กจะถูกขยายก่อนอ่าน
  ภาพที่ยาวมาก (เว็บตูน) จะถูกแบ่งเป็นช่วงที่ซ้อนกันเล็กน้อย ถ้า OCR.space ใช้ไม่ได้และเลือกภาษาต้นฉบับไว้
  จะใช้ Tesseract ในเบราว์เซอร์แทน
- **หาบอลลูน** — แนวทางแบบคลาสสิกจากงานวิจัย (connected components ของพื้นที่ว่างรอบตัวอักษร):
  ไล่หาพื้นหลังรอบข้อความทีละพิกเซล (รองรับกระดาษที่แสงไม่เท่ากัน) ถ้าพื้นหลังถูกล้อมปิด = บอลลูน
  แล้วประมาณรูปตัวบอลลูนโดยไม่นับหาง บรรทัดในบอลลูนเดียวกันจะรวมเป็นกล่องเดียว บอลลูนที่ติดกันจะไม่ปนกัน
- **แปลภาษา** — ฝั่งเซิร์ฟเวอร์ใช้คลังคำศัพท์ก่อน (คำอุทาน เสียงประกอบ คำเรียกขาน และคำศัพท์ของเรื่องที่ผู้ใช้ตั้ง
  ในแท็บ "คำศัพท์") แล้วแปลส่วนที่เหลือด้วย Google Translate (สำรองด้วย MyMemory) ข้อความตัวพิมพ์ใหญ่ทั้งหมด
  จะถูกแปลงเป็นตัวพิมพ์ปกติก่อนแปลเพื่อให้ได้ความหมายที่ถูกกว่า คลังคำสำเร็จรูปมีหลายพันคำจากอังกฤษ ญี่ปุ่น เกาหลี
  และจีน (คำอุทาน SFX คำเรียกขาน ศัพท์กำลังภายใน วังหลวง และเว็บตูน) ค้นหาได้ในแท็บ "คำศัพท์" กด + เพื่อคัดลอก
  มาแก้คำแปลเอง หรือวางหลายคำพร้อมกันแบบบรรทัดละคำ (`ต้นฉบับ = คำแปล`)
- **สำนวนการแปล** (เมื่อแปลเป็นไทย) — ทั่วไป, กันเอง (ฉัน/นาย), สุภาพชาย (ผม/ครับ), สุภาพหญิง (ฉัน/ค่ะ/คะ),
  ห้าว/นักเลง (ข้า/แก), ย้อนยุค/กำลังภายใน (ข้า/เจ้า) — ปรับสรรพนาม คำลงท้าย และคำอย่าง ขอบคุณ/ขอบใจ ให้เข้ากับสำนวน
  โดยไม่แตะชื่อในคลังคำ ("คุณ" หน้าชื่อยังเป็นคำนำหน้าชื่อ) และตัดจุดท้ายประโยคแบบที่ภาษาไทยไม่ใช้
- **ลบข้อความเดิม** — ลบเฉพาะก้อนหมึกที่อยู่ในบริเวณข้อความ (เส้นขอบบอลลูนและลายเส้นอื่นไม่ถูกแตะ)
  แล้วเติมสีจากรอบ ๆ เข้าไปให้กลืนกับกระดาษหรือพื้นไล่สี เลือกเองได้ว่าจะลบกล่องไหน: ช่อง "ลบข้อความเดิม"
  ในรายการ หรือโหมด "เลือกกล่องที่จะลบ" ซึ่งแสดงผลลัพธ์สด ๆ — คลิกกล่องเพื่อเลือก/ยกเลิก และวาดกรอบ
  ตรงข้อความที่ OCR หาไม่เจอเพื่อลบทันที (กรอบที่วาดเป็นแค่เครื่องหมายบอกให้ลบ ไม่ใช่กล่องข้อความ)
  หน้าที่ลบไปแล้วจะอัปเดตภาพตามการเลือกให้เอง
- **จัดวางและดาวน์โหลด** — ข้อความในบอลลูนกลมจัดบรรทัดตามรูปวงรี (บรรทัดกลางยาว บน-ล่างสั้น) รองรับการตัดคำภาษาไทย
  และไม่ขึ้นบรรทัดใหม่ด้วยเครื่องหมายวรรคตอน โค้ดจัดบรรทัดชุดเดียวกันใช้ทั้งตอนแสดงผลและตอน export
  ภาพที่ดาวน์โหลดจึงตรงกับที่เห็นใน editor
- งานทั้งหมดบันทึกอัตโนมัติไว้ใน IndexedDB ของเบราว์เซอร์ (ไม่มีการอัปโหลดเก็บไว้ที่เซิร์ฟเวอร์)
